
## File database RPM untuk VLOOKUP

Bro Cahyo mengarahkan format yang benar: file harus berupa **database Excel** agar bisa dipakai VLOOKUP saat layout RPM berbeda.

File yang sudah dibuat:
- `02 DASAR-DASAR PROGRAM KEAHLIAN RPL/DATABASE_KOMPONEN_RPM_VLOOKUP.xls`

Isi file:
- 1 baris = 1 RPM
- 1 kolom = 1 field data
- kolom RPM_ID, JP, identitas, DPL 1-8, mapel lintas jurusan, elemen/CP/TP/ATP, pemahaman bermakna, pertanyaan pemantik, 3M, asesmen, sumber belajar, pengayaan/remedial, refleksi guru, K3LH, 5R, catatan tambahan

Fungsi file:
- menjadi sumber data untuk VLOOKUP
- memudahkan Bro Cahyo membuat layout RPM berbeda tanpa mengubah sumber datanya
- menjaga konsistensi data antar RPM
