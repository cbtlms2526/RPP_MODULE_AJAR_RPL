- catatan penggunaan DPL yang relevan untuk setiap RPM
- koreksi istilah DPL 2 Kewargaan

- alur 3M
- asesmen
- sumber belajar

File ini diposisikan sebagai file kesusu agar Bro Cahyo bisa cek dan edit manual dengan mudah.
