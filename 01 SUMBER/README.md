# 01 SUMBER

Folder ini berisi semua sumber referensi untuk penyusunan RPM / modul ajar RPL.

Isi penting:
- file analisis pembelajaran mendalam
- blueprint RPM
- file master komponen RPM
- contoh dokumen RPM
- CP/ATP/acuan resmi
- catatan rujukan materi

Prinsip utama:
- gunakan pendekatan pembelajaran mendalam
- patuhi alur Memahami, Mengaplikasi, Merefleksi
- kelas X = Fase E
- kelas XI dan XII = Fase F
- gunakan DPL yang relevan pada setiap RPM
- pakai koreksi istilah DPL 2 Kewargaan
